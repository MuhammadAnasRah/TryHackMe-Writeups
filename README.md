# TryHackMe Writeups

A collection of my notes and write-ups from completing rooms and challenges on [TryHackMe](https://tryhackme.com/). I use this repository to document what I learn, the approaches I take, the problems I encounter, and the security concepts I want to understand better.

The aim is to keep a record of my practical cybersecurity learning—not just the final answers or flags.

## About This Repository

I am building my skills in cybersecurity, with a particular interest in penetration testing and offensive security. Working through TryHackMe rooms gives me a place to practise concepts in a controlled environment and improve my understanding through hands-on exercises.

Each write-up is based on my own lab experience. Depending on the room, it may include:

- Room overview and learning objectives
- Lab environment and tools used
- Reconnaissance and enumeration
- Findings and vulnerability analysis
- A high-level account of the approach taken
- Challenges and troubleshooting
- Key concepts learned and areas to revisit

The level of detail may vary between write-ups as I continue learning and improve how I document my work.

## Tools and Technologies

Tools used vary by room. Some of the tools I have worked with include:

- **Nmap** — network scanning and service enumeration
- **Gobuster** — web directory and resource discovery
- **Burp Suite** — web application testing
- **Netcat** — network connection and listener utilities
- **Kali Linux** — penetration-testing environment

I only list tools in an individual write-up when they are relevant to that room and my notes.

## What I Am Working On

Through these exercises, I am developing my understanding of:

- Network reconnaissance and service identification
- Web application security
- Linux fundamentals and permissions
- Vulnerability assessment
- Privilege-escalation concepts
- Writing clear technical reports

I also use the write-ups to identify topics that need more practice, rather than treating completion of a room as proof that I have mastered the subject.


Each room has its own folder and write-up so that notes remain organized and easy to follow.


Some details, such as flags, target addresses, or sensitive exploit instructions, may be omitted from public write-ups.
